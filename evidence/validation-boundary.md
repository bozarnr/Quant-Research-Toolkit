# Validation Boundary

This repository is a toolkit foundation. It demonstrates how the research
interfaces are structured and tested, but it does not claim a live alpha.

Current evidence:

- Synthetic data demo only.
- Unit tests for data-contract checks, leakage rejection, Rank IC diagnostics,
  transaction-cost handling, and registry metadata.
- No private data or employer implementation details.

What would be needed before stronger claims:

- Point-in-time public data with a reproducible download manifest.
- Walk-forward or frozen sample-out evaluation.
- Neutralization and exposure diagnostics.
- Cost assumptions linked to venue, liquidity, and rebalance frequency.
- Independent adversarial review for leakage, survivorship bias, and multiple
  testing.
